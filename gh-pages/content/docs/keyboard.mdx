The shortcut bar stays on screen at all times, so you never have to come back
here. This is the same list, plus the details that do not fit on a chip.

## While reviewing a file

| Key | Action |
|-----|--------|
| <Key>Enter</Key> | Rename, or save into the armed folder. Applies a pending video trim too. |
| <Key>Ctrl+F</Key> / <Key>⌘F</Key> | Choose or create a subfolder |
| <Key>Ctrl+D</Key> / <Key>⌘D</Key> | Move to `_deleted/` — works while typing |
| <Key>Delete</Key> | Move to `_deleted/` — only when not typing |
| <Key>Ctrl+Space</Key> / <Key>⌘⇧Space</Key> | Skip without changing anything |
| <Key>←</Key> <Key>→</Key> | Previous / next file |
| <Key>Ctrl+Z</Key> / <Key>⌘Z</Key> | Undo the last action |

## Panels and video

| Key | Action |
|-----|--------|
| <Key>Ctrl+M</Key> / <Key>⌘M</Key> | Toggle the metadata panel |
| <Key>Ctrl+B</Key> / <Key>⌘B</Key> | Batch optimize |
| <Key>Ctrl+O</Key> / <Key>⌘O</Key> | Options |
| <Key>[</Key> <Key>]</Key> | Set the video trim start / end |
| <Key>?</Key> | Help overlay |
| <Key>Esc</Key> | Cancel the armed folder, or close a modal |

<Callout>
<Key>Ctrl+D</Key> keeps working while the cursor is in the name field, because
deciding a photo is junk usually happens halfway through naming it.
<Key>Delete</Key> does not, for the obvious reason.
</Callout>
